OUTLET MIX NORDESTE — PRIMEIRO ESBOÇO ESTÁTICO

Como visualizar:
1. Extraia o arquivo ZIP.
2. Abra o arquivo index.html em um navegador moderno.
3. Para uma experiência mais próxima de produção, sirva a pasta com um servidor local simples.

Estrutura:
- index.html: página inicial
- catalogo/: catálogo com busca, filtros e ordenação
- promocoes/: campanhas e ofertas
- historia/: página institucional
- contato/: contato e formulário demonstrativo
- politicas/: retirada, transporte, trocas e garantia
- produto/: página dinâmica de produto por parâmetro ?id=
- assets/: logotipo, imagens de referência, mapa e produtos
- css/style.css: identidade visual responsiva
- js/data.js: dados simulados do catálogo
- js/main.js: slider, pesquisa, carrinho, filtros e interações

Recursos demonstrativos:
- Slider automático com navegação
- Catálogo responsivo
- Busca global e busca do catálogo
- Filtro por categoria e ordenação por preço/desconto
- Carrinho persistido no navegador (localStorage)
- Simulação de pedido pelo WhatsApp
- Páginas de produto geradas a partir dos dados locais
- Formulário de contato sem backend
- Layout adaptado para celular, tablet e desktop

Observação:
Os preços, produtos, estoque, avaliações, endereço visual e campanhas são dados de demonstração e devem ser substituídos pelas informações oficiais antes da publicação.
